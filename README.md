# vivo X Fold 外接屏「免投屏确认」MacroDroid 宏

> 给 vivo X Fold（V2178A）在 OriginOS 5 下外接显示器使用时，自动点掉「镜像到外接显示屏」确认弹窗。
> 导入即用：**下载一个 `.macro` 文件 → 用 MacroDroid 打开 → 打开开关**，不需要自己搭触发器。
---

## 这是什么

OriginOS 5 在接入外接显示器（USB-C DP / 扩展坞）时会弹出确认框，问你是否「镜像到外接显示屏」，必须手动点一下「是」才能出画面。

- OriginOS 4：没有这个确认框，但 SystemUI 有 density 渲染问题；
- OriginOS 5：渲染问题修了，但**每次接入都要点确认，系统里没有任何「记住选择」的开关**，也没有可关闭的持久化设置项。

本仓库提供一个为「无屏使用 / 桌面化改装」场景准备的 MacroDroid 宏：检测到外接屏接入或弹窗出现时，自动完成点击链（点「镜像到显示屏」→ 点「是」→ 必要时再点一次入口）。

**全部通过无障碍（Accessibility）模拟点击实现，不 root、不改系统分区、不写设置项，随时可关可删。**

## 三步导入（懒人路径）

### 第一步：下载宏文件

到本仓库 [Releases](https://github.com/<你的用户名>/<仓库名>/releases) 页面下载最新的：

```
vivo-xfold-mirror-auto-click.mdr
```

### 第二步：用 MacroDroid 打开

1. 手机上下载好文件（浏览器下载目录即可）；
2. 用文件管理器点它，或长按 → 打开方式 → 选择 **MacroDroid**；
3. MacroDroid 会弹出导入确认，点「导入」。

> 如果点了没反应：打开 MacroDroid → 右上角菜单 → 「导入 / 导出」→ 选择该文件。

### 第三步：开开关 + 授权

1. 回到 MacroDroid 宏列表，找到 **「镜像到外接显示屏」**，把右侧开关打开；
2. 首次运行会提示需要无障碍权限，按引导进入系统设置 → 无障碍 → **已下载的服务** → 打开 **MacroDroid**；
3. 若提示「读取屏幕内容」，同样允许（这是屏幕内容触发器和文本匹配点击的前提）；
4. 建议在系统设置里给 MacroDroid 关掉电池优化（后台保活），否则息屏久了可能被系统冻结。

完成。之后每次接上外接屏，弹窗会被自动点掉。

## 常见问题

**Q1：导入成功、开关也开了，但不自动点？**

按顺序排查：

1. **无障碍没开或被杀**：系统设置 → 无障碍 → 已下载的服务 → MacroDroid 是否为开启状态（部分系统会在重启后关闭第三方无障碍服务）；
2. **屏幕内容读取权限**：MacroDroid 设置里确认「读取屏幕内容」相关权限已授予；
3. **后台被冻结**：把 MacroDroid 加入电池优化白名单 / 后台高耗电允许；
4. **手动测一次**：MacroDroid 里长按该宏 → 「测试宏」，看日志卡在哪一步（点击成功但界面没变，通常是匹配文本对不上，见 Q2）。

**Q2：系统更新后弹窗文字变了，点不到？**

本宏的点击是靠**文本匹配**（不是坐标），所以文字一变就失效。改法：

1. MacroDroid → 该宏 → 编辑 → 动作列表 → 点开对应「界面交互」动作；
2. 把里面的文本改成新文案（例如「镜像到外接显示屏」），保存；
3. 如果是触发器里的「屏幕内容」匹配不到，同样进触发器把文本改掉。

> 小技巧：MacroDroid 的界面交互动作支持额外填 resource-id 兜底，但 resource-id 由系统 SystemUI 决定，系统更新后同样可能变，属于进阶操作，本仓库不做保证。

**Q3：其他机型能用吗？**

不建议直接套用。虽然触发逻辑是通用的（检测外接屏接入 → 点确认），但：

- 弹窗文案不同（各家叫法不一样）；
- 有的系统根本没有这个确认框（比如 OriginOS 4），装上也不会有任何效果；
- 部分机型的外接屏确认走的是系统级窗口，无障碍不一定能读到。

想移植请按 Q2 的方式自行改文本并实测，作者不对其他机型负责。

**Q4：MacroDroid 免费版只能用 5 个宏，会冲突吗？**

免费版限制是「同时最多 5 个宏」，与本宏本身无关。如果你已经有 5 个宏在用，需要先停用/删掉一个才能再导入。付费版（Pro）是买断制、无订阅，按需自行决定，**本仓库不提供、也不分发任何破解版或安装包**。

**Q5：接上外接屏后画面出来了，但点完之后又弹一次？**

宏的第 7 个动作就是为这种情况留的：在等待 5 秒后再点一次「镜像到显示屏」入口。若你的场景是「点完确认后系统又要求重新进入投屏」，可以把这个动作的等待时间调长一点再试。

## 附录：宏配置明细（想手改的人看这里）

以下从作者原始配置中提取，供需要自己重建或改造的人参考。还带有几个无用可禁用删除的宏。

### 基本信息

| 项 | 值 |
|---|---|
| 宏名称 | 镜像到外接显示屏 |
| 分类 | 未分类 |
| 变量 | 无（无全局变量、无局部变量） |
| 动作块 | 无 |
| 约束条件 | 无（任何情况下触发都生效） |
| 导出时状态 | 启用 |

### 触发器（4 个，任一满足即触发）

| # | 触发器类型 | 参数 |
|---|---|---|
| 1 | USB 设备连接 | 设备类型：任意 USB 设备（option=0） |
| 2 | 电源连接 | 仅「已连接」时触发；连接方式包含 USB（三个连接类型选项均为开） |
| 3 | 屏幕内容 | 匹配文本：`镜像到显示屏`；区分大小写：否；包含悬浮窗：否；匹配方式：0 |
| 4 | 屏幕内容 | 匹配文本：`连接`；区分大小写：否；包含悬浮窗：否；匹配方式：0 |

> 匹配方式数字含义以 MacroDroid 编辑界面显示为准（0/1 分别对应界面上的两种文字匹配模式），本文按界面原样标注，避免误改。

### 动作（7 个，按执行顺序）

| # | 动作 | 参数 | 状态 |
|---|---|---|---|
| 1 | 等待直到触发 | 定时器 10 秒；超时 5 秒后继续执行 | 启用 |
| 2 | 界面交互 → 点击 | 文本 `连接`；匹配方式 0 | **已禁用**（备用） |
| 3 | 界面交互 → 点击 | 文本 `管理文件`；匹配方式 1 | **已禁用**（备用，含 USB 存储选择场景） |
| 4 | 界面交互 → 点击 | 文本 `镜像到显示屏`；匹配方式 1 | 启用 |
| 5 | 界面交互 → 点击 | 文本 `是`；匹配方式 1 | 启用 |
| 6 | 等待直到触发 | 定时器 5 秒；超时 5 秒后继续执行 | 启用 |
| 7 | 界面交互 → 点击 | 文本 `镜像到显示屏`；匹配方式 1 | 启用 |

### 设计说明

- **为什么用屏幕内容触发器而不是固定延时**：弹窗出现时机不固定（取决于外接屏握手速度），界面变化驱动比盲等更稳；
- **为什么第 2、3 个动作默认禁用**：这两步只在「USB 存储选择」类弹窗出现时才需要，常态下点了会误触，所以留作开关，需要时手动启用；
- **为什么全是文本匹配、没有坐标点击**：坐标点击在不同分辨率/DPI/横竖屏下会错位，文本匹配对分辨率不敏感，代价是系统改文案后要手动更新（见 Q2）。
